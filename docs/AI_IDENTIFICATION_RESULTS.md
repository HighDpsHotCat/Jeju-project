# 카메라 동물 식별 시연

모델 버전은 `jeju-5-5d8ac780b1`이다. 한 마리가 크게 나온 성체 사진을 대상으로 한다. 촬영, 갤러리 선택, 기존 기록 재식별 모두 동일한 사진 처리 코드와 가중치를 사용한다. 파일명, GPS, 촬영 시각은 모델 입력에 들어가지 않는다.

## 지원 종과 독립 사진 평가

학습과 판정 기준 설정이 끝난 뒤 새로운 관찰 사진 84장을 고정했다. 서로 다른 촬영자 84명 중 학습·기준 설정에 참여한 촬영자는 0명이다. 모델 비교용 시험에 등장한 촬영자는 8명이며 사진과 관찰 ID는 전부 새 것이다. 추가 표본은 시연 예시를 고르기 전에 평가했다.

| 실제 종 | 사진 수 | 올바른 AI 제안 | 후보 검토 | 미확인 |
|---|---:|---:|---:|---:|
| 노루 | 8 | 5 | 1 | 2 |
| 참새 | 8 | 6 | 2 | 0 |
| 칠성무당벌레 | 8 | 3 | 4 | 1 |
| 붉은귀거북 | 8 | 1 | 3 | 4 |
| 청개구리 | 1 | 1 | 0 | 0 |

지원 종 33장 중 16장에 종을 제안했고 16장이 맞았다. 나머지 17장은 후보 검토 또는 미확인으로 표시했다. 대상 밖 51장에서는 45장을 미확인으로, 3장을 후보 검토로 처리했고, 3장에 지원 종을 잘못 제안했다. 오제안은 유럽노루 2장과 붉은귀거북의 근연 아종 1장에서 발생했다. 전체 제안 정밀도는 16/19, 지원 종 제안 비율은 16/33이다. 이 수치와 청개구리 1장으로 당초의 95% 정밀도·80% 제안율 목표 달성을 주장할 수 없다. 인쇄물·화면 재촬영과 실제 휴대폰 카메라의 정확도 및 지연은 별도 검증이 필요하다.

Chrome 릴리스 빌드의 실제 사진 선택 창에서 시연용으로 고른 종별 사진 1장씩을 열어 5개 국명·분류군을 모두 확인했다. 같은 화면에서 꽃 사진 1장은 미확인으로 표시됐다. 이 여섯 장은 기능 시연용으로 선별했으며 위 통계에는 중복 합산하지 않았다. Android ARM64 릴리스 빌드, Flutter 자동 테스트 10개, 정적 분석도 통과했다.

## 모델과 개발용 비교 결과

공개 DINOv2-small 양자화 ONNX 모델로 224×224 RGB 사진에서 384차원 CLS 벡터를 얻고, 5개 종과 비교용 동식물 17개 부류를 학습한 로지스틱 회귀로 점수를 계산한다. 비교 부류 점수는 합산한다. 1·2위 점수 차이, 검증 사진에서 정한 종별 점수 하한, 해당 종 중심과의 코사인 유사도로 제안·검토·미확인을 구분한다. 붉은귀거북 양성 표본은 눈 뒤의 붉은 무늬가 특징인 아종 *Trachemys scripta elegans*로 한정했다. AI 결과와 사용자의 확인은 독립적으로 저장된다. [원본 특징 추출 모델](https://huggingface.co/facebook/dinov2-small) · [ONNX 배포본](https://huggingface.co/Xenova/dinov2-small/tree/c2bb04a51fab207c420665f1946016107bffc701)

iNaturalist의 야생·연구등급 관찰에서 사진별 라이선스를 확인하고 관찰당 한 장을 골랐다. 촬영자별 분할과 파일 해시 중복 제거 후 1,653장을 사용했다. 학습 931장, 기준 설정 251장, 모델 비교용 시험 471장이다. 이 시험 결과를 바탕으로 초기 MobileNet 모델을 교체했으므로 위의 추가 평가와 따로 보고한다. 개발 시험에서 지원 207장 중 119장에 올바른 종을 제안했다. 대상 밖 264장에서는 10장을 지원 종으로 잘못 제안했다. 다섯 종만 강제 선택했을 때의 1순위 정답 204/207은 사용자가 실제로 보는 제안율과 다르다. ## 재현

일반 앱 실행에는 `python tool/prepare_identification.py`와 Flutter가 필요하다. 브라우저에서도 실행하려면 준비 명령에 `--web`을 추가한다. 모델과 웹 런타임은 지정 버전에서 받아 SHA-256을 검사하고 앱에 묶는다. 기기에서는 사진 업로드나 API 키 없이 추론한다.

학습과 평가를 재현하려면 Python 3.13 환경에서 다음 명령을 실행한다. 사진과 기본 모델 파일은 Git에서 제외했다. 매니페스트에는 관찰 ID, 사진별 저작자 표시, 출처 URL과 라이선스가 들어 있다. 사진이 삭제되거나 변경되면 다운로드 또는 해시 검증에서 확인할 수 있다.

```sh
python -m pip install -r ai/requirements-identification.txt
python tool/prepare_identification.py
python ai/collect_photos.py ../jeju-training --manifest ai/identification_observations.jsonl.gz
python ai/train_identification.py ../jeju-training
python ai/audit_identification.py evaluate ../jeju-audit
flutter test
```
