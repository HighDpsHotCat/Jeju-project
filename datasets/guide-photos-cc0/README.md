# 제주 동물 도감 사진 후보 자료

iNaturalist 공개 API에서 수집한 도감 73종의 사진 95장입니다. 확인일은 2026-11-16입니다. 자료는 도감 종 ID와 학명으로 조회할 수 있습니다.

- `photos/`에 사진을, `manifest.json`에 사진 ID, 도감 종 ID, 학명, 관찰자 계정, 사진별 출처 페이지와 이용허락, 파일 해시를 저장했습니다. 관찰자 계정은 관찰 게시자를 뜻합니다.
- `jeju_bbox` 84장은 제주 본섬과 연안의 경계 상자(북위 33.16–33.59°, 동경 126.12–126.99°)에서 찾았습니다. `global_reference` 11장은 지역 제한 없이 검색한 종 참고 사진입니다.
- 연구 등급 야생 관찰 중 관찰과 사진 모두 [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/)으로 표시된 항목을 선별했습니다. 각 사진의 권리 표시는 목록의 `photo_page`에서 확인할 수 있습니다.
- 도감 학명이 유일하게 대응되는 종에 한해 종당 최대 2장을 저장했습니다. 아종은 관찰 학명을 별도로 보존합니다. 중간 크기 이미지를 JPEG로 다시 저장해 파일 메타데이터를 제거했습니다.
